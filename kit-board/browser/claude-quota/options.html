Personal Observatory · browser collector 2.0.0

Connect Claude allowances

This collector reads allowance percentages and reset times from an open Claude tab at the Observatory's cadence and uploads them as allowance readings. It never reads conversations, exports Claude cookies, or uploads token counts, organization names, or your email.

Health

1. Pair with the Observatory

In the Observatory open Settings → Connections → Add browser, label this browser profile, and paste the one-time code here.

2. Bind the signed-in Claude account

Find the account this profile is signed into, then bind one organization to the Observatory account that owns its readings. Use the same account id the legacy connection used so the history stays on one card.

3. Collect

Legacy v1 bridge (reconciliation period only)

A v1 connection keeps publishing to the old quota endpoint beside the v2 upload so old and new readings can be compared. Both carry the same observation time; the Observatory shows such a pair once, as the v2 reading. When the v1 source is disabled in the Observatory, remove the connection here to finish the cutover for this profile.

Keep Claude open in this browser profile. If you sign into a different account, collection pauses and says so above. Personal subscription allowances are separate from Console API billing.
