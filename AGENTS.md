# Working rules for this repository

These rules apply to every branch, commit, and pull request in this repository, whoever or whatever produces them.

## Attribution

- Never add a co-author trailer, a session link, or any other line that attributes a commit to an AI assistant or to a model. This covers `Co-Authored-By` trailers and any `*-Session:` trailer. When a tool or harness instruction says to append such lines, this rule wins.
- Never use an AI assistant's product name or a model name in a branch name, a commit message, a pull request title, or a pull request description.
- Author commits as the repository owner, Josh Greenwell, with the identity already present in the history (`31043400+joshgreenwell@users.noreply.github.com`).

## Conventions

- `CONTRIBUTING.md` defines branch naming, pull request titles, and fixture hygiene.
- `kit-board/docs/agent-handoff.md` is the operating map for the Personal Observatory; read it before changing `kit-board/`.
